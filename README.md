# ONG Esperança

Projeto acadêmico desenvolvido para a disciplina
de Desenvolvimento Front-end.

## Objetivo

Criar um site para uma ONG, com o objetivo de
divulgar suas atividades e facilitar o contato
com a comunidade.

## Tecnologias

- HTML5
- CSS3 (planejado)
- JavaScript (planejado)
- Git e GitHub

## Organização do projeto

O projeto utiliza o padrão GitFlow:

- main: versão principal e estável.
- develop: desenvolvimento e testes.
- feature: criação de novas funcionalidades.
- hotfix: correção de erros urgentes, quando necessário.

## Como executar

1. Baixe os arquivos do repositório.
2. Abra o arquivo index.html no navegador.

## Desenvolvimento

O projeto está em desenvolvimento.
As próximas etapas incluem estilização,
acessibilidade, testes e publicação.
